# Roadmap backend API

Порядок реализации эндпоинтов MELIST. Контракты — [api.md](api.md), нумерация функций — [docs/README.md](../README.md). Монетизация (27–29: реклама, донаты, entitlements) **вне скоупа** этого файла.

Статусы: **готово** — не заглушка; **очередь** — `501`; **клиент** — не API.

Агент, закрывая эндпоинт: отметь его **готово** в этом файле и поправь «Статус реализации» в [api.md](api.md). Не вычёркивай монетизацию отсюда — её здесь нет.

## Сейчас

Готово: auth (access JWT + refresh cookie), CRUD вишлистов, CRUD желаний, содержимое списка, сортировка вишлистов, шеринг по ссылке, избранное, профиль, чужой публичный профиль, подписки.

Монетизация (27–29) вне скоупа.

### 8. Профиль (22, 23, 26) — готово

Upsert пользователя при `POST /auth/validate` пишет строку `users` (включая `avatar_url`). `GET /api/me` тоже создаёт запись из JWT, если её ещё нет.

| Эндпоинт | Функции | Статус |
|---|---|---|
| `GET /api/me` | 22, 26 | готово |
| `PATCH /api/me` | 23, 26 | готово |

`GET /api/me/entitlements` (29) — монетизация, не здесь.
