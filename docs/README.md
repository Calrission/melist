# MELIST

MELIST — Telegram Mini App для создания виш-листов к праздникам. Пользователь создаёт вишлист, добавляет в него желания (подарки) и делится им с другими: публично или только по ссылке.

## Структура репозитория

```
melist/
├── frontend/   # Flutter Web (Telegram Mini App)
├── backend/    # Dart Frog API + PostgreSQL
├── core/       # общие модели (melist_core)
└── docs/       # документация
```

Пакеты собраны в Dart workspace (`pubspec.yaml` в корне): один `pubspec.lock`, зависимости между пакетами без версий.

## Функционал продукта

Нумерация используется в [api.md](backend/api.md) для привязки эндпоинтов к функциям.

### Вишлисты

1. Создание вишлиста
   - 1.1. Указание названия
   - 1.2. Выбор видимости (публичный / черновик)
   - 1.3. Опциональное добавление уже существующих желаний
   - 1.4. Выбор цвета из базовой палитры
2. Просмотр вишлистов
   - 2.1. Список всех своих вишлистов
   - 2.2. Детальная карточка каждого вишлиста
3. Редактирование вишлиста
   - 3.1. Изменение названия
   - 3.2. Смена видимости (публичный / черновик)
   - 3.3. Смена цвета оформления
4. Управление желаниями внутри вишлиста
   - 4.1. Добавление новых желаний
   - 4.2. Добавление уже существующих своих желаний
   - 4.3. Копирование желаний с чужих вишлистов
5. Сортировка
   - 5.1. Порядок вишлистов в общем списке (перетаскиванием)
   - 5.2. Порядок желаний внутри вишлиста (перетаскиванием)
6. Удаление вишлистов
   - 6.1. Одиночное удаление
   - 6.2. Множественное удаление
7. Шеринг вишлиста
   - 7.1. Формирование ссылки для публичного доступа
   - 7.2. Поделиться вишлистом

### Избранное

8. Добавление чужого вишлиста в избранное
   - 8.1. По ссылке-приглашению
9. Просмотр избранных вишлистов
   - 9.1. Список всех избранных вишлистов
10. Сортировка избранных вишлистов
    - 10.1. Изменение порядка отображения в списке избранного
11. Удаление из избранного
    - 11.1. Убрать вишлист из избранного

### Желания

    - 12.2. Опциональные поля: цена, ссылка, описание, обложка
13. Дублирование желания

16. Просмотр всех желаний

17. Поиск желаний
    - 17.1. Поиск по названию
    - 17.2. Фильтрация по своим желаниям
18. Редактирование желания
    - 18.1. Название
    - 18.2. Цена
    - 18.3. Ссылка
    - 18.4. Описание
    - 18.5. Обложка
19. Смена видимости желания
    - 19.1. Публичный
    - 19.2. Приватный (только мне)

20. Смена статуса исполнения желания
